# ainitShot documentation

Project documents: requirements, glossary, decisions and open questions. The structure grows with the project: new folders appear once there is material for them.

## Statuses

- **Draft** — under discussion, nothing decided yet.
- **Accepted** — the decision is recorded.
- **Partially accepted** — part of the document is accepted, the rest is a draft.
- **Living list** — updated continuously.
- **Superseded** — for decisions: a later decision replaced this one, and the record stays as it was.

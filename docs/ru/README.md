# Документация ainitShot

Здесь собраны документы по проекту: требования, терминология, решения и открытые вопросы. Структура растёт вместе с проектом: новые папки появляются, когда для них набирается материал.

## Статусы

- **Черновик** — обсуждаем, решения не приняты.
- **Принято** — решение зафиксировано.
- **Принято частично** — часть документа принята, остальное — черновик.
- **Живой список** — постоянно пополняется.
- **Заменено** — о решениях: его заменило более позднее решение, а запись осталась как была.

| [Требования](requirements.md) | Что делает программа и как выглядит: инструменты, действия и что не берём | Принято частично |
| [Терминология](glossary.md) | Единый язык проекта | Черновик |
| [Решения](decisions/README.md) | Почему проект устроен именно так: каждое решение с вариантами и доводами | Живой список |

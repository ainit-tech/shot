# Решения

Каждое решение записано один раз: вопрос, какие варианты мы рассматривали, почему выбрали именно этот и что из этого следует. Страницы, которые описывают проект, приводят только результат и ссылаются сюда словом «почему». На сайте у такой ссылки виден номер решения, а при наведении — что в решении сказано.

<!-- decisions: list -->

## Как записывается решение

- Запись короткая. Абзац под заголовком формулирует решение, дальше идут вопрос, варианты с доводами за и против каждого, почему выбран этот и последствия.
- **Черновик**: варианты разложены, но ничего ещё не решено. **Принято**: решение принято. **Заменено**: его заменило более позднее решение.
- Запись говорит, каким решение стало. Если она оказалась неверной, неполной или записанной неточно, исправляют саму запись, а сайт хранит её прежние версии и показывает, что изменилось. Запись заменяется, только когда на её вопрос отвечает другая запись.
- Вопросы, за которые ещё не брались, собраны в [открытых вопросах](../open-questions.md). Когда варианты разложены, вопрос становится черновиком решения.

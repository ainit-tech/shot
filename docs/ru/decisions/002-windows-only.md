# Только Windows

Программа делается только для Windows.

## Вопрос

Программой пользуются на одном компьютере с Windows 11. Нужно ли, чтобы она работала ещё и на Linux и macOS?

## Варианты

| Вариант | За | Против |
|---|---|---|
| Только Windows | Всё нужное встроено в Windows: горячие клавиши для всей системы, захват экрана, буфер обмена, распознавание текста. Проверять нужно на одной системе | Больше нигде не работает |
| Windows, Linux и macOS | Работает везде | Каждая система снимает экран и отдаёт горячие клавиши по-своему; на macOS и на Linux с Wayland программе нужно разрешение пользователя, чтобы снимать экран. В разы больше работы для программы, которой один человек пользуется на Windows |

## Почему

Программа делается для одного человека, а он работает на Windows. Другие системы умножили бы работу, а пользоваться результатом было бы некому.

## Последствия

- Код обращается к Windows напрямую, без прослойки для других систем.
- Части, которые общаются с Windows (захват, горячая клавиша, буфер обмена, браузер), держатся отдельно от рисования и действий, чтобы их можно было заменить, если когда-нибудь понадобится другая система.

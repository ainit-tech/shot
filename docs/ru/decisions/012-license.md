# Лицензия программы

Решено: ainitShot — свободная программа под GNU General Public License версии 3 или любой более поздней (GPL-3.0-or-later). Любой может пользоваться программой, изучать её, менять и передавать дальше; кто передаёт изменённую версию, передаёт и её исходный код под той же лицензией.

## Вопрос

ainitShot публикуется с открытым кодом ([решение](009-the-name-ainitshot.md)). Под какой лицензией — так, чтобы код оставался открытым и никто не сделал из него закрытую программу?

## Варианты

| Вариант | За | Против |
|---|---|---|
| Закрытая и бесплатная | Код остаётся у автора | Никто не может проверить, что делает с экраном программа, которая его видит; нет бесплатной подписи кода для проектов с открытым кодом |
| Разрешительная лицензия: MIT, Apache-2.0 или BSD | Меньше всего условий; обычна для Rust | Любой может закрыть копию, добавить рекламу и продавать её как свою |
| CC0-1.0, без сохранения прав | Нечего соблюдать | Не предназначена для программ и не одобрена Open Source Initiative |
| GPL-3.0-only | Каждая копия остаётся открытой, именно под этой версией | Код не может перейти на более позднюю версию GPL |
| GPL-3.0-or-later | Каждая копия остаётся открытой; код может перейти на более поздние версии GPL | Условия более поздних версий определяет Free Software Foundation |

## Почему

У программы, которая видит весь экран и отправляет картинки в Google, код должен быть доступен любому. GPL сохраняет это для каждой копии: изменённую версию передают вместе с исходным кодом, так что никто не превратит ainitShot в закрытую программу с рекламой. Программы для скриншотов ShareX, Flameshot и Greenshot тоже под GPL-3.0. Форму «или любой более поздней версии» советуют сами авторы лицензии.

## Как работает

- Текст лицензии — файл `LICENSE` в корне репозитория, а `Cargo.toml` называет её: `GPL-3.0-or-later`.
- Библиотеки, которые использует программа, — под лицензиями MIT, Apache-2.0, BSD, Zlib и похожими, которые сочетаются с GPL-3.0. Их лицензии требуют, чтобы их уведомления шли вместе с программой: раздел «О программе» окна настроек перечисляет каждую встроенную в неё библиотеку и модель, которую она скачивает, с текстом лицензии каждой, и показывает собственную лицензию программы. Список пишет `tools/licenses.py` по зависимостям, а тест находит список, который им больше не соответствует.
- Лицензия распространяется на код; прав на имя ainitShot она не даёт.

## Следствия

- Изменение, которое вносит кто-то другой, приходит под той же лицензией.
- Лицензию одобрила Open Source Initiative, а этого требует бесплатная подпись кода для проектов с открытым кодом.

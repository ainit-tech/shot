# Версия для macOS

Пока не решено, будет ли у ainitShot версия для macOS. Программа сделана только для Windows ([решение](002-windows-only.md)), поэтому версия для Mac — это перенос программы, а не настройка сборки. Здесь взвешены варианты и цена.

## Вопрос

Должен ли ainitShot работать и на macOS, и чего это потребует?

## Варианты

| Вариант | За | Против |
|---|---|---|
| Только Windows, как сейчас | Ничего не делать | Пользователи Mac остаются без программы |
| Перенос части для Windows на Rust, остальное общее | Та же программа на Mac, такая же быстрая и маленькая; рисование, настройки, запросы, страницы окон и переводы остаются общими | Нового кода примерно столько же, сколько в части для Windows; для проверки нужен Mac |
| Кроссплатформенный фреймворк (Tauri, Electron) для всего | Один код для всех систем | Снимок экрана, горячие клавиши и замороженный экран всё равно требуют своего кода для каждой системы; программа становится тяжелее и медленнее |

## Что потребует перенос

Около 4 500 строк программы от Windows не зависят и остаются как есть: выделение, пометки и волшебный карандаш, рисование, панели, запросы, настройки и переводы. Так же остаются страницы окон (настройки, презентация, приглашение, выбор языка) — с небольшой правкой того, как страница говорит с программой.

Часть для Windows, около 7 700 строк, пишется для Mac заново:

| В Windows | На Mac |
|---|---|
| Снимок экрана через GDI | ScreenCaptureKit, после того как пользователь разрешит запись экрана |
| Замороженный экран — окно поверх каждого монитора | Окно поверх каждого дисплея, выше всего |
| Горячая клавиша (RegisterHotKey) | RegisterEventHotKey из Carbon |
| Значок в области уведомлений | Пункт в строке меню |
| Буфер обмена, окно сохранения | NSPasteboard, NSSavePanel |
| Распознавание текста Windows | Vision от Apple |
| WebView2 для Google и окон | WKWebView |
| Текст через GDI | Core Text |
| Автозапуск, уведомления | Объект входа (SMAppService), User Notifications |
| Установщик, обновления | Приложение в `.dmg`, обновления из того же `latest.json` |

Риски:

- Google может не дать войти внутри WKWebView: он считает его встроенным браузером.
- Вопрос голосом зависит от распознавания речи в WKWebView.
- Без Mac программу никто не проверит.

## Сборка и деньги

- У SourceCraft нет сборщиков macOS — ни в облаке, ни собственных. Для сборки нужен Mac:
  - сборщики macOS есть в GitHub Actions: бесплатно для открытого репозитория и с ограниченными минутами для закрытого;
  - или собственный Mac в роли сборщика.
- Без подписи и нотаризации Apple macOS останавливает программу при первом запуске. Apple Developer Program стоит $99 в год.

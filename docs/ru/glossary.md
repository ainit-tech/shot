# Терминология

Этот словарь — единый язык проекта. Документы, схемы, интерфейс и код используют одни и те же слова в одном и том же значении. Если нужного термина здесь нет, его сначала добавляют сюда и только потом используют.

Во всей документации термины из этого словаря подчёркнуты точками, а при наведении на термин появляется подсказка с его значением.

## Правила

1. **Один термин — одно значение.** Синонимов нет: если для понятия выбрано слово, другим словом его не называем.
2. **Термин пишется одинаково везде**: в документах, на схемах и в интерфейсе. В коде используется имя из карточки.
3. **Не занимаем чужие слова.** Если известная программа уже называет каким-то словом другое понятие, мы это слово не берём.
4. **У каждого термина указан вид**: инструмент, часть интерфейса, сущность и так далее. Так инструмент не спутать с панелью, на которой он лежит.
5. **Термины меняются только целиком.** Новый термин сначала получает статус «предложен». Принятый термин переименовывают только вместе со всеми документами, схемами и кодом.
6. **Переводы берут слова из базы терминов.** Русская версия и версия на хинди используют только эквиваленты из [базы терминов](#база-терминов).

## Статусы

- **Принят** — термин утверждён.
- **Предложен** — термин уже используется, но ещё не утверждён.
- **Под вопросом** — есть проблема или несколько вариантов, нужно решение.

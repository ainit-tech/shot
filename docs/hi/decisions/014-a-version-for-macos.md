# macOS के लिए संस्करण

अभी तय नहीं: क्या ainitShot का macOS के लिए संस्करण होगा। प्रोग्राम सिर्फ़ Windows के लिए बना है ([निर्णय](002-windows-only.md)), इसलिए Mac का संस्करण प्रोग्राम का पोर्ट है, बिल्ड की कोई सेटिंग नहीं। यह रिकॉर्ड विकल्पों और लागत को तौलता है।

## सवाल

क्या ainitShot को macOS पर भी चलना चाहिए, और इसके लिए क्या चाहिए होगा?

## विकल्प

| विकल्प | पक्ष में | विपक्ष में |
|---|---|---|
| सिर्फ़ Windows, जैसे अभी | कुछ करना नहीं | Mac के उपयोगकर्ता प्रोग्राम के बिना रहते हैं |
| Windows वाले हिस्से का Rust में पोर्ट, बाक़ी साझा | Mac पर वही प्रोग्राम, उतना ही तेज़ और छोटा; ड्रॉइंग, सेटिंग्स, क्वेरी, विंडो के पेज और अनुवाद एक ही रहते हैं | लगभग उतना ही नया कोड, जितना Windows वाले हिस्से में है; जाँच के लिए Mac चाहिए |
| सबके लिए क्रॉस-प्लेटफ़ॉर्म फ़्रेमवर्क (Tauri, Electron) | हर सिस्टम के लिए एक कोड | स्क्रीनशॉट, हॉटकी और जमी हुई स्क्रीन के लिए फिर भी हर सिस्टम का अपना कोड चाहिए; प्रोग्राम भारी और धीमा होता है |

## पोर्ट के लिए क्या चाहिए

प्रोग्राम की लगभग 4,500 पंक्तियाँ Windows पर निर्भर नहीं हैं और वैसी ही रहती हैं: चयन, निशान और जादुई पेंसिल, ड्रॉइंग, टूलबार, क्वेरी, सेटिंग्स और अनुवाद। विंडो के पेज (सेटिंग्स, प्रस्तुति, न्योता, भाषा का चुनाव) भी रहते हैं, बस पेज प्रोग्राम से कैसे बात करता है, उसमें छोटा बदलाव।

Windows वाला हिस्सा, लगभग 7,700 पंक्तियाँ, Mac के लिए नए सिरे से लिखा जाता है:

| Windows पर | Mac पर |
|---|---|
| GDI से स्क्रीनशॉट | ScreenCaptureKit, उपयोगकर्ता के स्क्रीन रिकॉर्डिंग की अनुमति देने के बाद |
| जमी हुई स्क्रीन, हर मॉनिटर के ऊपर विंडो | हर डिस्प्ले के ऊपर, सबसे ऊपर विंडो |
| हॉटकी (RegisterHotKey) | Carbon का RegisterEventHotKey |
| नोटिफ़िकेशन एरिया में आइकन | मेनू बार में आइटम |
| क्लिपबोर्ड, सेव करने की विंडो | NSPasteboard, NSSavePanel |
| Windows की टेक्स्ट पहचान | Apple का Vision |
| Google और विंडो के लिए WebView2 | WKWebView |
| GDI से टेक्स्ट | Core Text |
| Windows के साथ शुरू होना, सूचनाएँ | लॉगिन आइटम (SMAppService), User Notifications |
| इंस्टॉलर, अपडेट | `.dmg` में ऐप्लिकेशन, उसी `latest.json` से अपडेट |

जोखिम:

- Google, WKWebView को एम्बेड किया हुआ ब्राउज़र मानकर, उसके अंदर साइन इन करने से मना कर सकता है।
- बोलकर पूछना WKWebView में वाक् पहचान पर निर्भर है।
- Mac के बिना कोई प्रोग्राम की जाँच नहीं कर सकता।

## बिल्ड और पैसे

- SourceCraft के पास macOS वर्कर नहीं हैं — न उसके क्लाउड में, न अपने। बिल्ड के लिए Mac चाहिए:
  - GitHub Actions में macOS वर्कर हैं: सार्वजनिक रिपॉज़िटरी के लिए मुफ़्त, निजी के लिए सीमित मिनट;
  - या वर्कर के रूप में अपना Mac।
- Apple के हस्ताक्षर और नोटराइज़ेशन के बिना macOS प्रोग्राम को पहली शुरुआत पर रोक देता है। Apple Developer Program की लागत साल में $99 है।

# केवल Windows

प्रोग्राम केवल Windows के लिए बनाया जाता है।

## प्रश्न

प्रोग्राम Windows 11 वाले एक कंप्यूटर पर इस्तेमाल होता है। क्या इसे Linux और macOS पर भी चलना चाहिए?

## विकल्प

| विकल्प | पक्ष में | विपक्ष में |
|---|---|---|
| केवल Windows | ज़रूरी सब कुछ Windows में पहले से है: पूरे सिस्टम के लिए हॉटकी, स्क्रीन कैप्चर, क्लिपबोर्ड, टेक्स्ट पहचान। जाँचना एक ही सिस्टम पर है | और कहीं नहीं चलता |
| Windows, Linux और macOS | हर जगह चलता है | हर सिस्टम स्क्रीन को अपने तरीके से कैप्चर करता है और हॉटकी अपने तरीके से देता है; macOS पर और Wayland वाले Linux पर स्क्रीन कैप्चर करने के लिए प्रोग्राम को उपयोगकर्ता की अनुमति चाहिए। ऐसे प्रोग्राम के लिए कई गुना ज़्यादा काम, जिसे एक व्यक्ति Windows पर इस्तेमाल करता है |

## क्यों

प्रोग्राम एक व्यक्ति के लिए बनाया जाता है, और वह Windows पर काम करता है। दूसरे सिस्टम काम को कई गुना बढ़ा देते, और नतीजे का इस्तेमाल करने वाला कोई नहीं होता।

## परिणाम

- कोड सीधे Windows को कॉल करता है, दूसरे सिस्टमों के लिए कोई परत नहीं।
- Windows से बात करने वाले भाग (कैप्चर, हॉटकी, क्लिपबोर्ड, ब्राउज़र) ड्रॉइंग और क्रियाओं से अलग रखे जाते हैं, ताकि अगर कभी दूसरा सिस्टम चाहिए हो, तो उन्हें बदला जा सके।

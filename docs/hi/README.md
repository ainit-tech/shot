# ainitShot दस्तावेज़

यहाँ परियोजना के दस्तावेज़ हैं: आवश्यकताएँ, शब्दावली, निर्णय और खुले प्रश्न। संरचना परियोजना के साथ बढ़ती है: नए फ़ोल्डर तब बनते हैं, जब उनके लिए सामग्री जमा हो जाती है।

## स्टेटस

- **मसौदा** — चर्चा जारी है, अभी कोई निर्णय नहीं हुआ।
- **स्वीकृत** — निर्णय दर्ज हो चुका है।
- **आंशिक रूप से स्वीकृत** — दस्तावेज़ का एक हिस्सा स्वीकृत है, बाकी मसौदा है।
- **लगातार अद्यतन सूची** — यह सूची लगातार बढ़ती रहती है।
- **बदला गया** — निर्णयों के लिए: बाद के किसी निर्णय ने इसकी जगह ले ली, और रिकॉर्ड वैसा ही रहता है।
